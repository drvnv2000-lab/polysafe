Does knowing a patient's drugs help predict kidney injury in the ICU?

A pre-registered study of 2,520 ICU stays from 186 US hospitals, with every drug exposure classified by a pharmacist.

A small gain, in one model only

Adding five drugs (vancomycin, piperacillin-tazobactam, furosemide, NSAIDs and contrast) to the pre-specified logistic regression improved how well it ranks patients by risk.

LightGBM, a more flexible model that already did better on clinical data alone, gained nothing. The improvement is real for the planned model, and model-specific.

Exploratory, specified after the results were seen (D10.1). The marker is present in 89% of stays, so this check is weak.

Does it hold up?

The same comparison under other cohorts, baselines and validation schemes. Hover or tap a row for what changed. These were named before modelling; how they were run was fixed after the primary result was seen, and the protocol says so.

Which drugs travel with kidney injury?

Odds ratios adjusted for illness severity with a propensity score. Ondansetron, an anti-nausea drug with no kidney effect, is the negative control: if it lit up, the adjustment would be failing. Associations, not causes.

Every decision, dated

The analysis plan was committed before any model was trained. It can only grow: a test fails on any commit that edits an earlier line. Corrections are entries, not edits, including the one that says a sensitivity plan was finalised after the results were seen.

    What this does not show

    • That drugs add information a flexible clinical model cannot find on its own.
    • That this model should guide care or prescribing. No individual patient's risk is shown anywhere: 78 events cannot support it.
    • That the result holds at hospitals without medication capture, or outside this sample.
    • Anything causal about these drugs.
